# 指标公式与口径

本文档记录系统中每个指标的**精确计算方式**(与代码一致,非近似描述)。
统一约定见 §2,已知冗余与口径不一致见 §6。

数据流:
```
tushare 期权日线 + ETF/指数日线
  └─ src/research/surface_history.py   → 曲面因子(逐日)  surface_<key>_*.parquet
  └─ scripts/build_gex.py              → GEX 时序         gex_<key>.json
       └─ scripts/build_timing_viz.py  → 衍生+百分位+合并  timing_viz.json
            └─ scripts/build_equity.py → 仓位/净值/超额    equity.json
```

## 1. 曲面因子(`src/research/surface_history.py`)

### 1.1 逐日预处理

| 步骤 | 做法 |
|---|---|
| 合约价 | `price = settle if settle > 0 else close`(结算价优先) |
| 无风险利率 | `R = 0.02`(常数) |
| 跳过到期周 | 只用剩余期限 `DTE ≥ 5` 的到期月 |
| **平价隐含远期** | `F = K + e^{RT}·(C − P)`,取距现价最近 **4** 个行权价的**中位数**;失败回退 `F = S` |
| 等效现货 | `S_eff = F·e^{−RT}`(代入现货式 BS,使前向价 = F) |
| **只用虚值** | `K ≥ F` 用 call、`K ≤ F` 用 put(实值合约价≈内在价值,IV 反解不稳) |
| 反解 IV | 二分法(`src/pricing/black_scholes.implied_vol`),保留 `0.02 < IV < 3` |
| 有效性 | 需 ≥4 个有效点,且 call/put 各 ≥2 个,否则该到期月作废 |

> **为何用远期 F 而非现货 S**:ETF 期权受分红/持有成本影响,远期常低于现货。
> 若用 S 作平值基准,会把分红效应误读成偏斜。

### 1.2 常数 30 日期限插值

```
lo = max{DTE ≤ 30}      hi = min{DTE ≥ 30}
w  = (30 − lo) / (hi − lo)          # 夹在 [0,1]
指标 = 指标(lo) + w · [指标(hi) − 指标(lo)]
```
即对包住 30DTE 的两个到期月分别算全部指标,再按 DTE 线性插值。

### 1.3 各因子

以下 `IV_put25`、`IV_call25` 指在**虚值微笑**上按 `|delta| = 0.25` 插值得到的 IV。
BS delta:`Δ_call = Φ(d₁)`,`Δ_put = Φ(d₁) − 1`,`d₁ = [ln(S/K) + (r + σ²/2)T] / (σ√T)`。

| 字段 | 公式 | 含义 |
|---|---|---|
| `spot` | 标的收盘价 | — |
| `atm_iv` | 虚值微笑在 `K = F` 处对行权价插值的 IV | 波动率**水平** |
| `iv_call_25d` | 虚值 call 上 \|Δ\|=0.25 处插值 IV | — |
| `iv_put_25d` | 虚值 put 上 \|Δ\|=0.25 处插值 IV | — |
| `iv_ratio_25d`(情绪比) | `IV_put25 / IV_call25` | **偏斜**;>1 = 认沽更贵(防御) |
| `skew_25d` | `IV_put25 − IV_call25` | **偏斜**;正 = 下跌偏斜 |
| `rr_25d` | `IV_call25 − IV_put25` = **−`skew_25d`** | **偏斜**(标准 RR 口径);负 = 下跌偏斜 |
| `bf_25d`(蝶式) | `(IV_call25 + IV_put25)/2 − atm_iv` | 凸度/微笑深度 |
| `iv_ratio_15m` | `IV(K=F·0.85) / IV(K=F·1.15)` | 固定虚值情绪比(中金原口径) |
| `rr_15m` | `IV(K=F·1.15) − IV(K=F·0.85)` | 固定虚值 RR |
| `smile_slope`(微笑斜率) | IV 对 moneyness 的**线性回归斜率**,仅用 \|K/F − 1\| ≤ **12%** 区间;单位 = 每 +1% moneyness 的 IV 百分点变化 | **偏斜**;负 = 低行权价 IV 更高 |
| `pcr_vol` / `pcr_oi` / `pcr_amount` | **近月**(最近到期月)`Σput / Σcall` 的 成交量 / 持仓量 / 成交额 | 情绪辅助 |

> ⚠️ 25Δ 插值用 `np.interp`,**越界会夹取最近端点**(为保证时序连续)。
> 合约稀疏的交易日拿到的可能不是真正的 25Δ,而是最接近的可得 delta。

## 2. 恐慌方向统一约定

代码中各因子的符号沿用市场标准口径,**恐慌方向并不一致**。统一记法:定义
**"恐慌分位"= 该因子在恐慌时趋于变大的方向上的分位**。

| 因子 | 原始字段 | 恐慌时原始值 | 恐慌分位 = |
|---|---|---|---|
| 水平·高IV | `atm_iv` | ↑ 变大 | `iv_pct` |
| 偏斜·情绪比 | `iv_ratio_25d` | ↑ 变大 | `sent_pct` |
| 偏斜·RR | `rr_25d` | ↓ 变小 | **`1 − rr_pct`** |
| 偏斜·微笑斜率 | `smile_slope` | ↓ 变小(更负) | **`1 − slope_pct`** |
| VRP | `vrp` | ↓ 变小(转负) | **`1 − vrp_pct`** |

**记法约定(建议后续统一沿用)**:凡涉及 put/call 的差与比,一律 **put 在前 / 在分子**
(`put − call`、`put / call`),这样"数值越大 = 越恐慌"。`rr_25d` 是唯一 call 在前的字段
(标准 RR 口径),它 **恒等于 −`skew_25d`**,使用时注意方向。

## 3. 衍生指标(`scripts/build_timing_viz.py`)

| 字段 | 公式 |
|---|---|
| `rv`(已实现波动) | 过去 **20** 日对数收益标准差 × √252,`min_periods=10` |
| `vrp`(方差风险溢价) | `atm_iv − rv` |
| `mom20`(20日动量) | `price / price[t−20] − 1` |
| `dd20`(20日回撤) | `price / max(price[t−19 … t]) − 1` |
| `sent` | = `iv_ratio_25d`(改名) |
| `rr` / `slope` / `pcr` | = `rr_25d` / `smile_slope` / `pcr_vol`(改名) |

### 滚动百分位

```
pct(x, t) = #{ x[s] ≤ x[t] : s ∈ [t−win+1, t] } / win
```

| 分位字段 | 窗口 | min_periods |
|---|---|---|
| `iv_pct`, `sent_pct`, `rr_pct`, `slope_pct`, `vrp_pct`, `pcr_pct` | **63** 交易日 | 31 |
| `mom_pct`(动量分位) | **252** 交易日 | 126 |

> 百分位在**全样本**上计算后再按显示区间截断,因此"924 以来"视图中每一天的分位
> 仍包含此前的历史,不因截断失真。

## 4. GEX(`scripts/build_gex.py`)

每交易日取**最近月**(`DTE ≥ 3`)全部合约:

```
IV_i    = BS 反解(close 价, 现货 S, 无远期修正)        # 注:与 §1 口径不同,见 §6
gamma_i = φ(d₁) / (S · σ_i · √T)
GEX     = Σ_i  gamma_i · OI_i · MULT · S² · 0.01 · sign_i
          sign = +1 (call) / −1 (put)      MULT = 10000
gex_z   = (GEX − mean₂₅₂(GEX)) / std₂₅₂(GEX)          # min_periods=60
max_oi_k = argmax_K Σ(call OI + put OI)                # 最大持仓行权价
```

- 有效日需 ≥3 张合约成功反解,否则跳过。
- **系统只使用 `gex_z`**(标准化后无量纲),故 `MULT` 对指数期权不精确不影响信号。
- 含义:`gex_z` 低/负 = dealer 空 gamma = 波动放大;高 = 抑制波动。**预测波动大小,非方向**。

## 5. 信号合成

### 5.1 恐慌五灯(63 日分位,阈值 0.90 / 0.10)

```
高IV  : iv_pct    ≥ 0.90
情绪比: sent_pct  ≥ 0.90
RR    : rr_pct    ≤ 0.10        ( ⟺ 恐慌分位 1−rr_pct ≥ 0.90 )
斜率  : slope_pct ≤ 0.10
VRP   : vrp_pct   ≤ 0.10
灯数 k = 满足条件的个数 (0~5)
```

### 5.2 抄底触发档(灯数 × 动态跌幅)

```
红·重仓 : k ≥ 3  且  mom_pct ≤ 0.04
橙·加注 : k ≥ 2  且  mom_pct ≤ 0.08
黄·关注 : k ≥ 1  且  mom_pct ≤ 0.15
```
双条件:**灯亮 + 已跌到位**,缺一不触发。

### 5.3 melt-up 过热(仅警示,非做空)

```
mom_pct ≥ 0.85  且  iv_pct ≥ 0.75  且  vrp_pct ≥ 0.75
```

### 5.4 今日期权动作(信号台,优先级自上而下)

| 条件 | 动作 |
|---|---|
| 抄底档 ≥ 黄 | 🟢 抄底 / 买 call |
| melt-up 过热 | 🟣 减仓·收紧止盈(**不买 put**) |
| `iv_pct ≤ 0.25` | 🔵 低波 → 布局 2 周 put 保险(创业板/沪深300优先) |
| 其他 | ⚪ 常态持有观望 |

### 5.5 仓位(净值报告 `build_equity.py`,信号台已不显示)

```
panic = mean(iv_pct, sent_pct, 1−rr_pct, 1−slope_pct, 1−vrp_pct)      # 恐慌度
gate  = clip((0.30 − mom_pct) / 0.30, 0, 1)                           # 跌幅门
buy   = panic · gate · clip(1 − 0.4·gex_z, 0.4, 1.5)                  # GEX 调节

纯期权:  target = 0.30 + 0.70 · clip((buy − 0.15)/0.30, 0, 1)
         过热时 target = min(target, 0.15)
         出场棘轮:未达目标时每日最多下调 4%;动量分位 ≥0.85 或过热则快速减
HVWMA:   HVWMA 方向为绿 → max(0.65, 抄底目标);红 → 抄底目标
换手成本: 5 bps × |仓位变化|
```

## 6. 已知冗余与口径不一致

### 6.1 偏斜类因子高度冗余(实测)

`rr_25d ≡ −skew_25d`(恒等,`corr = −1.000`)。且情绪比 / RR / 斜率**方向对齐后相关性 0.91~0.97**:

| 方向对齐后 | 高IV | 情绪比 | RR | 斜率 | VRP |
|---|---|---|---|---|---|
| 高IV | 1.00 | 0.05 | 0.14 | 0.04 | 0.05 |
| 情绪比 | | 1.00 | **0.97** | **0.91** | 0.24 |
| RR | | | 1.00 | **0.92** | 0.25 |
| 斜率 | | | | 1.00 | 0.31 |
| VRP | | | | | 1.00 |

→ **"五灯"实为三维度**:①水平(高IV) ②偏斜(情绪比/RR/斜率,占 3 盏) ③VRP。
当前灯数把偏斜**重复计了 3 次**(panic 权重中偏斜占 60%)。这也解释了统计现象:
"≥1~2 盏灯已捕获大部分 edge、5 盏样本只有个位数"——偏斜三盏几乎同亮同灭。

### 6.1b 冗余处理的验证结论(`scripts/dedup_factors.py`)

在"跌到位"(`mom_pct ≤ 0.15`)的 541 个事件上,对未来 20 日收益的区分力:

| 恐慌度定义 | IC | 高半区胜率 | 低半区胜率 | 胜率差 |
|---|---|---|---|---|
| P5 现状(偏斜60%) | +0.213 | 64.1% | 51.3% | +12.8% |
| P3eq 去重(各维33%) | +0.116 | 62.2% | 53.1% | +9.1% |
| **单·偏斜** | **+0.302** | **70.3%** | 45.2% | **+25.0%** |
| 单·高IV | +0.038 | 57.4% | 57.9% | −0.5% |
| 单·VRP | −0.028 | 54.0% | 61.2% | −7.3% |

分标的 IC(偏斜均 / 高IV / VRP):沪深300 `+0.22 / +0.09 / −0.21`、
中证1000 `+0.34 / +0.02 / +0.30`、科创50 `−0.09 / +0.21 / −0.21`、创业板 `+0.62 / −0.19 / −0.01`。

**三条结论**:
1. **"去重成等权三维"反而更差**(IC 0.213→0.116)——因为它把唯一有效的偏斜维度权重从 60% 稀释到 33%。
   现状的"重复计 3 次"歪打正着地放大了有效信号。
2. **偏斜是唯一稳定有效的维度**(3/4 标的 IC 为正);**高IV 与 VRP 在"已跌到位"条件下符号来回翻**,
   基本是噪音。科创50 是例外(唯独它靠高IV、偏斜反向),再次印证其性格不同。
   ⚠️ 但这**不意味 IV 无用**——它在 melt-up 过热判定与低波 put 保险信号中明确有效,
   其角色是**划分 regime**,而非在跌幅内排序质量。
3. **改权重对实际策略近乎无影响**(924后四标的平均夏普:P5 现状 1.50 / 去重 1.47 / 纯偏斜 1.54 /
   偏斜.8+IV.2 1.49;平均超额 +5.4% / +5.6% / +5.4% / +5.0%)。因为 `gate` 跌幅门做了大部分工作、
   ramp 映射饱和、棘轮出场主导路径,恐慌度只是乘数。

→ **处理决定:保留现状 P5 口径不改代码**。改动收益落在噪音范围内,而现行口径已被
《恐慌择时警告》报告与全部历史回测验证过,改动会使既有结论需全部重跑。冗余作为
**已知特性记录在此**:解读时应知"偏斜三盏是同一个证据",不要把 3 盏灯当成 3 个独立确认。
这也与"建模保持简单、alpha 在粗结构"的既有结论一致。

### 6.2 两套 IV 反解管线 —— 已验证:**差异实质存在,建议统一**

| | 曲面(§1) | GEX(§4) |
|---|---|---|
| 合约价 | `settle`(回退 close) | `close` |
| 平值基准 | 平价隐含远期 F | 直接现货 S |
| 期限 | 常数 30 日插值 | 最近月 |

实测(`scripts/gex_pipeline_check.py`,口径A=现状 close+现货,口径B=统一 settle+远期):

| | `gex_z` 相关性 | 符号一致率 | 低GEX(z≤−1)判定一致率 | GEX>0 占比 A/B |
|---|---|---|---|---|
| 沪深300ETF (n=1526) | **0.610** | 78.6% | 90.9% | 91% / 86% |
| 创业板 (n=868) | 0.898 | 88.9% | 91.8% | 96% / 94% |

**沪深300 两口径的 `gex_z` 仅 0.61 相关**——不能认为"标准化后即等价"。
但策略实际使用的"低 GEX 区判定"一致率约 **91%**,故对信号方向影响有限
(GEX 在仓位公式里只作 `clamp(1−0.4·gex_z, 0.4, 1.5)` 的温和调节)。

→ **待办**:把 `build_gex.py` 的 IV 反解统一为 settle + 平价隐含远期(口径B),
理由是原则性的:settle 是官方结算标记,远期修正避免把分红读成偏斜。
统一后需重跑 GEX 强化的验证(K=0.4 是否仍最优)。

### 6.3 百分位窗口不统一 —— 已验证:**必须保留,不是缺陷**

因子分位用 **63** 日,动量分位用 **252** 日。曾疑为疏漏,实测(924后四标的)证明这是必要设计:

| 动量分位窗口 | 平均夏普 | 平均超额 |
|---|---|---|
| **252(现状)** | **1.50** | **+5.4%** |
| 126 | 1.45 | +4.0% |
| 63(与因子统一) | **1.13** | **−1.7%** |

统一成 63 日会**毁掉策略**(3/4 标的择时超额转负)。原因:63 日窗口太"局部"——
持续下跌时近 3 个月的分位会把跌幅"正常化",于是在小回调上乱触发、又认不出真正的
capitulation;**252 日是与整整一年比较,才能识别罕见跌幅**。→ 保留现状。
