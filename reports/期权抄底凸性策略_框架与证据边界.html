A股ETF/指数期权 · 择时研究

纯期权抄底凸性策略

恐慌灯触发 → 买近月看涨价差 → 到期前平仓。一条把"期权情绪信号"变成独立买方策略的加仓腿——连同它每一条被证伪的岔路,和它诚实的证据边界。

制定 2026-07-22标的 中证1000 / 500 / 创业板 / 科创50 / 300 / 上证50样本 2015–2026

一句话: 这是一个 regime 条件性的、小盘/成长专用的抄底买凸性策略。机制清楚、执行落地、每条改进路都验证过。但它的收益靠一条长尾撑着、regime 敏感、且受"小盘期权只到 2022"的数据墙所限,跨牛熊周期无法用历史证明。上线姿态 = 小仓位、机会型 sleeve、边跑边收样本外证据——不是一个被历史验证过的稳健 alpha。

核心机制

为什么是"买凸性",而不是别的

A股崩盘又急又猛、反弹常是V型——波动率不对称。在恐慌极值处买入便宜的看涨期权,用有限的权利金博一个又急又猛的反弹:多数交易小亏(权利金损耗),少数交易 +300~700%。这条正偏态长尾就是全部 alpha 的来源。

关键认知:期权在这里的价值不是"每单位名义跑赢指数"(它跑不赢),而是资金效率 + 风险封顶——用极小权利金撬动名义暴露,单笔亏损有底,于是敢按小比例重注,让复利吃到那条凸性长尾。

定案规格

多头凸性腿 · 最终参数

入场信号
恐慌灯 panic ≥ 0.70(五灯等权:高IV·高情绪比·低RR·低斜率·低VRP,63日滚动分位)+ 跌幅门。质量门是决定性杠杆:只靠跌幅门胜率~50%,加质量门 → 73%。
建仓时机
t+1 开盘。信号收盘出、次日开盘建——零前视且已验证 edge 存活(尾盘实时执行亦可)。
结构
近月(~30日)ATM 买 + 虚8%卖 的宽看涨价差;激进版为裸 ATM call。高IV抄底→宽价差卖掉部分 vega、对冲IV crush,保留大部分长尾。
出场
到期前 ~12 DTE 平仓(theta悬崖锚定)。吃满~3周反弹、留时间价值可卖,躲开临到期衰减。优于死扛,更优于持到期(0DTE被theta磨死)。
仓位
每笔押 ~15% 资金(最大亏损=权利金,天然风险封顶)。
适用标的
小盘/成长(中证1000最强,500·创业板·科创50可用);大盘无效(沪深300·上证50——阴跌无凸性)。
出场之所以"看似玄学的固定天数"是对的: "剩12DTE"= 近月最大gamma凸性 + 到期前两周离场 这两条真实规则的合成投影。固定天数只是它的近似。

Regime 架构

HVWMA + 200日线:各司其职

整套里最难的是 regime 检测。用三次独立转折(2019转牛 / 2022转熊 / 924转牛)验证检测器,得到两条硬结论:

检测器2019转牛2022转熊924转牛抖动/年
HVWMA(快)4日/+5%4日/−4%4日/+5%~20–27
200日线斜率(慢)107日/+44%123日/−19%21日/+36%~1
 数字 = 拐点滞后 / 错过涨幅(或转红前多跌)。仅用指数价格,4指数均值。
  • HVWMA 的低滞后是真的:三次转折都是 4–6 天,雷打不动。2019/2022 从未进过设计——"只是拟合924"被证伪。
  • 200线比单看924危险得多:924只晚21天是最仁慈的一次;2019晚107天、2022晚123天,真拐点上灾难级迟钝。
  • 但 HVWMA 太抖:regime段中位仅10天、54%两周内反转——是短线信号,不是regime。而且 panic 触发时它必红(价格在跌),没法门控多头。
由此定案(非对称分工): ① 多头该不该抄底 → 慢趋势(200线上行)门控(它对短回调迟钝,恰是优点);② 空头拐点紧急撤退 → HVWMA翻绿(4–6天确认,躲melt-up;撤空头便宜、假绿只少收carry、抖动在此无害)。HVWMA 不是regime开关,是"拐点确认器"。

空头腿

Bear call 价差:结构性更差的那条

下行regime里反弹卖看跌价差(卖低call+买高call,风险封顶)。可行但天花板低:胜率72%、终值1.28x,但均值仅 +0.3%/笔、负偏态(赢小赢频、亏大)——正是波动率不对称最差的那一侧。

  • 期权数据升级入场 → 无效:情绪比低("核心信号")用在空头反而亏(0.84x),粗动量反弹反而最好。"期权擅抄底不擅逃顶"再次应验。
  • 中性带防churn → 治标伤收益:能砍交易,但没有设置能既减churn又提收益。
  • churn只困扰空头:多头腿一年只在几个恐慌日触发、非重叠持仓~22天,横盘200线天天翻它也不在乎。
定位: 空头腿是"熊市里对冲核心多头book"的小仓位配菜,不是独立收益源。而且它是阴跌carry对冲、非崩盘对冲(收益封顶2%);要崩盘凸性保护应买 put 价差。

证伪档案

试过、并被数据否掉的路

记录同等重要——它们标出了不该再花力气的方向。

Risk Reversal(卖put+买call)证伪超额指数 ≈ −0.7%

≈ 合成多头指数(delta~0.8),skew红利扣成本后≈0,却用短put引入不封顶左尾。凸性 alpha 被线性化扔掉。

恐慌收敛出场(panic凉了就走)证伪2.58 → 1.6–1.8

赢家是delta驱动(反弹要几周),panic/IV冷却只要几天。"收敛就走"= 在delta行情起步时砍掉长尾。砍尾=砍命。

持有到期 / OPEX(0 DTE)证伪→ ≈1.0

被theta悬崖磨死中等赢家:还剩时间价值的赢家硬拖到到期,时间价值蒸发、OTM归零。

P&L 移动止盈证伪→ 1.5–1.8

日间期权市值波动±30–50%,移动止盈被噪声不断甩下车,中位从135%塌到−6%。

下行regime "抄了就跑" 快scalp证伪2日0.76 / 3日1.43 / 5日0.47

只有正好3天正=非单调尖峰=过拟合噪声。下行regime对买方长delta系统性敌意,任何持有期中位数全负。

期权数据判空头反弹入场证伪情绪比低 0.84x

过热镜像/情绪比低不管用,粗动量反弹反而最好。恐慌灯在底部灵,镜像在顶部没有择时力。

证据边界

能证明的 · 与不能证明的

已证明

机制(高IV抄底买凸性)· 结构/执行/出场参数 · regime检测机制(HVWMA低滞后在3次转折验证)· 小盘+924后确有强凸性收益 · 滑点/盘口/容量真实可承受。

未证明

跨牛熊周期的稳健性。唯一够老测2019/2022的50ETF是大盘蓝筹(策略无效);小盘期权最早2022。数据墙:历史数据无法给小盘凸性策略补上多周期验证。

50ETF 跨周期回测:全程1.14x/回撤−38%,所有周期都亏——但被混淆。铁证:同一924regime,50ETF亏0.85x vs 中证1000赚2.61x → 标的/凸性的影响 ≫ 周期。它的失败主要是"大盘无凸性",不能据此断定跨周期失效,也不能据此证明跨周期有效。

上线姿态

  • 当作 regime 条件性的机会型 sleeve——只在判断处于/进入"能V反弹"的小盘regime时开。
  • 小仓位、风险封顶(买方结构),接受它靠长尾吃饭、反弹不来就慢性放血。
  • 主战场 中证1000(+500);大盘不碰。
  • 用 向前的样本外时间 补跨周期证据——这是数据墙唯一的绕法。
  • 不当作历史验证过的稳健 alpha;不跨标的无脑摊开;不常年无脑开着。
